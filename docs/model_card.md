# Model card

> **Status: not yet trained.** The training, evaluation and export code is
> complete and tested; the model itself needs a GPU run on Kaggle or Colab
> (PRD decision D2). Every metric below is filled in by `ml/eval.py` and
> `ml/export.py`, not typed by hand. Until then `/about` and `/healthz` both
> report that no model is deployed rather than showing a stale figure.

## Intended use

Preliminary triage of crop-leaf disease from a photograph, for a farmer, an
extension worker or an agriculture student. It suggests what to look at and
explains how the disease develops.

## Out-of-scope use

- **Not a prescription.** Treatment text is general guidance. Local pathogen
  resistance, product registration and pre-harvest intervals vary by region, and
  a wrong fungicide timing is a real cost to a real person.
- **Not a certification or grading instrument.** It is not evidence of crop
  quality for a buyer or an insurer.
- **Not valid outside its 38 classes.** A crop it was never trained on will be
  refused if the abstain path fires, or filed as the nearest class it knows if it
  does not.
- **Not a substitute for a plant pathologist** on anything consequential.

## Data

| Source | Domain | Role |
| --- | --- | --- |
| PlantVillage | lab, uniform backgrounds | baseline, subsampled hard |
| PlantDoc | field | small (2,598), annotation noise is documented |
| PlantWild | in-the-wild | main field volume |

Target mixture is roughly one third lab, two thirds field — the ratio the prior
art validates. `data/taxonomy.yaml` maps every source label to one canonical
`crop___condition` id; anything unmapped **fails the manifest build** rather than
being dropped silently.

Splits are group-aware, so PlantVillage's scripted augmentation cannot straddle
train and validation. `test_field` is field images only and is never used for
model selection.

Full distribution in `docs/dataset_card.md`, generated by the manifest builder.

## Metrics

Reported by `ml/eval.py` into `docs/eval_report.md`:

- accuracy and macro-F1 on `test_lab` **and** `test_field`, with the domain gap
  as a headline number
- per-class F1 with the worst ten called out
- field confusion matrix
- ECE and a reliability diagram
- **background-bias probe** — the field set rescored with the leaf masked out
- abstain-rate curve

The headline metric is **field accuracy**. The lab number is context. Reporting
the lab number alone is what produces a 99% model that is useless in an orchard.

## Known failure modes

1. **Domain shift.** PlantVillage-trained models have collapsed from 99.35% to
   31.4% (Ferentinos 2018) and 99.72% to 41.81% (Gui et al. 2021) on field
   images. The mixture is designed against this; the probe measures whether it
   worked.
2. **Background reliance.** Models key on pots, benches, hands and lighting.
   The augmentation attacks it (coarse dropout, shadow, background replacement)
   and the probe quantifies whatever remains.
3. **Class imbalance.** Tomato is ~43% of PlantVillage. Capping and inverse-
   frequency weighting mitigate it; rare classes still have the worst F1.
4. **Label noise in PlantDoc**, documented upstream, which puts a ceiling on the
   field number.
5. **Confident wrong answers**, the dangerous mode for a farmer. This is what
   ECE measures and what the abstain path exists to catch.
6. **Visually similar diseases** — early blight versus target spot on tomato,
   Septoria versus bacterial spot — confuse in both directions.

## Abstain behaviour

Max-softmax **and** entropy must both pass, with thresholds tuned on a rejection
set of non-leaf photos, blurred leaves, hands and soil. A high top-1 with a broad
messy tail is refused; that is what the entropy term is for.

Below threshold the API returns `status: "uncertain"` with **no `disease_id`** —
enforced by a database check constraint, not just by application code — and the
XR module refuses to launch.

This is deliberate and it is the most important behaviour in the system. The XR
module narrates the life cycle of a *specific pathogen*. Narrating it for the
wrong pathogen is worse than saying nothing.

## Ethical and practical notes

- Uploaded images have **EXIF stripped before storage**, so GPS coordinates of
  someone's farm are not retained.
- The `/about` page publishes the field/lab gap and the background-probe result
  in plain language. If the probe shows the model is reading backgrounds, that
  goes on the page.
- Advice quality is bounded by the knowledge base, which currently covers apple,
  tomato and potato with citations on every field. Other diagnoses return no
  cycle rather than a generated one.
